# WishThemHappy


WishThemHappy is a web application used to create and share interactive, animated birthday cards. 

## Why this was made
Usually, sending a plain text message or a static image on WhatsApp to wish someone a birthday feels very boring and low-effort. We created this project so you can build a personalized, step-by-step birthday experience that feels like a digital gift. It has interactive components like 3D flipbooks, falling confetti, sound effects, custom letters, and digital fireworks to make the birthday person feel special.

## What it is used for
You can use this app to:
* Make personalized birthday cards for your friends, parents, or siblings.
* Customize the wishes, select background music, and upload photos.
* Choose different celebration themes .
* Generate a shareable link that contains the entire birthday card configuration. You can just copy the link and send it on WhatsApp or email, and the other person can open it instantly in their browser without downloading any app.

## How to run it locally

### 1. Install packages
```bash
npm install
```

### 2. Start the website
```bash
npm run dev
```
Open the link shown in your terminal (usually `http://localhost:5173`) in your browser to view the website.

### 3. Build for hosting
If you want to host it on Vercel, Netlify, or Github Pages:
```bash
npm run build
```
